# Microsoft Security Certification Study Notes

Welcome to this open study resource for Microsoft Security certifications. This site contains structured learning notes covering the **SC-900**, **SC-200**, and **SC-300** certification paths, designed to help you understand the material clearly and efficiently.

## What Is This Site?

This site was created to make studying for Microsoft Security certifications more accessible. The notes are written in plain, straightforward language and are organised to follow the official Microsoft Learn curriculum, so you can use them alongside Microsoft's own documentation or as a standalone revision resource.

Whether you are just starting out with cloud security concepts or looking to deepen your expertise in threat protection and identity management, you will find relevant material here.

## Certifications Covered

### 🔵 SC-900: Microsoft Security, Compliance, and Identity Fundamentals
An entry-level certification covering the foundational concepts of security, compliance, and identity across Microsoft cloud services. Ideal if you are new to Microsoft Security or working towards your first security qualification.
