# SC-300: Microsoft Identity and Access Administrator

!!! note "Exam Goal"
    Design, implement, and operate an organization's identity and access management systems using Microsoft Entra ID. Apply Zero Trust principles for identity and access solutions.

## 🧠 Key Themes to Remember

- **Microsoft Entra ID** — The core IAM platform for the entire exam → [Module 1](sc-300-user-identities.md)
- **Conditional Access** — The if-then policy engine for access control → [Module 2](sc-300-authentication-and-access.md#conditional-access)
- **Privileged Identity Management (PIM)** — Just-In-Time admin access → [Module 4](sc-300-identity-governance.md#privileged-identity-management-pim)
- **Entitlement Management** — Access packages and catalogs for governance → [Module 4](sc-300-identity-governance.md#entitlement-management)
- **Workload Identities** — Managed identities and app registrations → [Module 3](sc-300-workload-identities.md)
- **Hybrid Identity** — Entra Connect Sync and Cloud Sync → [Module 1](sc-300-user-identities.md#hybrid-identity)
- **Global Secure Access** — Microsoft's ZTNA / SSE solution → [Module 2](sc-300-authentication-and-access.md#global-secure-access)
